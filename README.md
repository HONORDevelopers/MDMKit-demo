## Introduction

In this sample code, you will use the created code project to call the interfaces of the Honor MDM Kit. Through this project, you will understand the usage and control effects of the MDM interfaces.

For more information, please refer to [Business Introduction](https://developer.honor.com/cn/docs/11015/guides/introduction).

## Environment Requirements

The recommended Android targetSdk version is 29 and above, and the JDK version is 1.8.211 and above.

## Hardware Requirements

A computer that can install JDK 1.8 and Android Studio, an Honor phone with a USB data cable for business debugging.

## Development Preparation

1. Register an Honor account and become an Honor developer.
2. Create an application and apply for the Honor MDM certificate. Refer to [Apply for Certificate](https://developer.honor.com/cn/docs/11015/guides/cert_apply).
3. To build this sample code, you need to import it into the Android integrated development environment. For detailed information, please refer to the [Development Guide](https://developer.honor.com/cn/docs/11015/guides/development_guide) integration preparation.

## Installation

1. Build a signed APK.
2. Package the MDM certificate into the signed APK.
3. Sign the APK with the packaged certificate again, and then it can be installed on the phone.

  Note: For details, please refer to the [Development Guide](https://developer.honor.com/cn/docs/11015/guides/development_guide).
